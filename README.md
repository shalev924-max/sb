# אתר שמואל ברגר

## מבנה הפרויקט

```
index.html            עמוד הבית (עברית, RTL)
en/index.html          עמוד באנגלית (LTR)
terms.html             תנאי שימוש ותקנון
privacy.html           מדיניות פרטיות
accessibility.html     הצהרת נגישות
assets/shmuel-berger.jpg   תמונת הפורטרט (משובצת גם כ-base64 בתוך ה-HTML עצמו, כך שהיא תמיד נטענת גם בלי התיקייה הזו)
robots.txt / sitemap.xml   קבצי SEO סטנדרטיים
```

כל עמוד הוא קובץ HTML עצמאי לחלוטין — CSS ו-JS מוטמעים בתוך הקובץ, בלי תלות בקבצים חיצוניים (מלבד גופנים מ-Google Fonts ושתי בקשות API חיצוניות, ראו בהמשך).

## לפני שהאתר עולה לאוויר

1. **דומיין**: יש להחליף את `https://www.shmuelberger.co.il/` בדומיין האמיתי בכל הקבצים (meta tags, JSON-LD, canonical, sitemap.xml, robots.txt).
2. **אימות פרטי קשר**: הכתובת, הפקס והטלפון במקור מבוססים על מסמך ישן — כדאי לוודא מול שמואל שהם עדכניים.
3. **בדיקה משפטית**: שלושת העמודים המשפטיים (terms/privacy/accessibility) נכתבו על בסיס מבנה סטנדרטי ותקנות ישראליות ידועות, אבל מומלץ מאוד שעורך דין יעבור עליהם לפני פרסום — הם לא נבדקו על ידי איש מקצוע מוסמך.

## תלויות ברשת (חשוב!)

שני חלקים באתר דורשים חיבור לאינטרנט **וגם אחסון אמיתי** (לא יעבדו כשפותחים את הקובץ ישירות מהמחשב, רק אחרי שהאתר יעלה לדומיין אמיתי):

- **טופס יצירת קשר** — נשלח דרך [FormSubmit](https://formsubmit.co) (ללא צורך במפתח API). בפעם הראשונה שמישהו שולח דרך הטופס, ייפתח מייל אימות ל-berger.finance@gmail.com שצריך לאשר פעם אחת.
- **שערי מטבע וסחורות** (בסרגל הנע ובקטע "שער הדולר") — נשלפים בזמן אמת מ-[Frankfurter](https://frankfurter.dev) (מטבעות) ו-[AURUM](https://aurumrates.com) (סחורות), שני מקורות חינמיים ללא מפתח API.

אם אחד מהשירותים האלה לא זמין (למשל בגלישה אופליין), האתר נופל בחזרה למספרים סטטיים קבועים מראש — לא יקרוס ולא יציג שגיאה.

## איך לעבוד על זה ב-VS Code

- אין build step, אין npm install — פשוט לפתוח את התיקייה ולערוך את קבצי ה-HTML ישירות.
- מומלץ להתקין את התוסף **Live Server** (Ritwick Dey) כדי לראות שינויים מתעדכנים בזמן אמת, ובעיקר כדי שהטופס ושערי המטבע יעבדו בבדיקה (הם לא עובדים מ-`file://`, אבל כן עובדים משרת מקומי כמו Live Server).
- וידג'ט הנגישות (הכפתור הכחול בפינה השמאלית התחתונה) מופיע בכל עמוד בנפרד — אם עורכים שינוי בו, צריך להעתיק אותו לכל חמשת הקבצים בנפרד (אין קובץ CSS/JS משותף).
